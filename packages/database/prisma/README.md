# Reconstructed schema provenance

The build pack references a validated `data/schema.prisma` containing 58 models and 33 enums, but that file was absent from the supplied archive. The founder approved reconstruction on 31 July 2026.

`schema.prisma` is reconstructed from specification §§12, 15, 17, 25, 27 and 29, the OpenAPI contract, the listed core entities, and the walking-skeleton requirements. It is intentionally production-shaped and will be reconciled model-by-model if the original schema is later supplied.
